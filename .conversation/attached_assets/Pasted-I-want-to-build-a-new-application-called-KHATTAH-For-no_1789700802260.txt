I want to build a new application called KHATTAH.


For now, create only a clean, professional foundation for the application.

KHATTAH CONCEPT
Khattah is a circle-based financial participation platform.
There is no rule limiting a participant to one reward per month.
CORE USER FLOW
A user can register and create an account.
A registered user can invite other people.
A user may invite many people, but the system will later determine which qualifying participants count toward completing that user's circle.
Do not implement detailed financial calculations yet.
USER STATUS COLORS
Use these status colors throughout the application:
Yellow = Registered / Invited
Green = Paid / Activated
Red = Eligible to Redeem / Receive Reward
Blue = Completed 24 house after being red

These colors should be clearly represented in the UI.
